Лабораторная работа №1. Разработка дизайна и базовых шаблонов.

Цель: Выбор темы, создание дизайна 3 страниц в Figma, разработка интерфейса на бэкенде.

Задание:

Выбрать тему: "Расчёт вращения звезд галактики Андромеды по кривой вращения".

В Figma разработать дизайн 3 страниц, скопировав стили (3 цвета, hover, карточки) с реального научного астрономического портала (NASA.gov).

Создать базовое приложение (Django/Go) с тремя страницами, используя данные в памяти (коллекции):

Страница 1 (Список расчетов): Плитка карточек доступных расчетов. Поле поиска по yfpdfyb.. Отдельная карточка "Текущий заказ" с количеством расчетов в нем.

Страница 2 (Детали расчета): Подробное описание выбранного расчета с полями.

Страница 3 (Черновик заказа): Просмотр черновика заказа. Ниже списком — карточки расчетов, добавленных в заказ, с полем комментария и точности справа.

Реализовать 3 GET-запроса для этих страниц. Фильтрация на сервере.

Интегрировать Minio. Хранить и отображать на всех страницах изображения, названия файлов указывать в модели.

Вынести CSS в отдельный файл. Использовать только базовые стили, без JavaScript.
