**Лабораторная работа №2. Разработка структуры базы данных.**

**Цель:** Создание структуры БД по теме и её подключение к бэкенду.

**Задание:**
1.  Разработать и реализовать структуру БД PostgreSQL для системы расчётов по кривым вращения. Обязательные таблицы:
    *   (расчёт)
    *   (заявка/заказ)
    *   (м-м заказ-расчёт)
    *   Пользователи
2.  Названия, типы и длина полей должны строго соответствовать предметной области. Добавить **4-6 специальных полей** в основные таблицы.
3.  Создать **ER-диаграмму** в StarUML с указанием таблиц, связей, типов столбцов, первичных и внешних ключей.
4.  Наполнить таблицы тестовыми данными через Adminer.
5.  Модифицировать приложение из ЛР1 для работы с БД через ORM:
    *   Получение и поиск расчётов.
    *   Добавление расчёта в текущий заказ (статус "черновик"). Если черновика нет — создать.
    *   Просмотр заказа с его расчётами.
6.  Реализовать **логическое удаление** заказа через **SQL-запрос UPDATE**, который меняет статус заказа на "удален". Удаленные заявки не отображать.
7.  Всего **5 HTTP-методов** в приложении: 3 GET (список, детали, заказ), 1 POST (добавить в заказ через ORM), 1 POST (удалить заказ через SQL).
