**Лабораторная работа №4. Авторизация и документация.**

**Цель:** Добавление аутентификации, Swagger и подготовка ТЗ.

**Задание:**
1.  Реализовать методы аутентификации (`/api/login/`, `/api/logout/`) и регистрации. Авторизация через куки/сессии (хранить в Redis) или JWT.
2.  Автоматически проставлять текущего аутентифицированного пользователя как создателя заказа.
3.  Добавить проверку прав (Permissions): методы завершения/отклонения заказа доступны только модераторам.
4.  Интегрировать Swagger/OpenAPI. Без авторизации доступны только `GET`-методы.
5.  Создать Sequence-диаграмму (StarUML) основного бизнес-процесса: аутентификация → список расчетов → добавление в заказ → формирование → завершение.
6.  Оформить разделы Технического Задания (ТЗ) в .doc: цель, задачи, функциональные требования, расчет аппаратных требований (ядра, ОЗУ, место на диске за 5 лет).
