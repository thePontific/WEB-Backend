**Лабораторная работа №3. Создание веб-сервиса (REST API).**

**Цель:** Разработка веб-сервиса со всей бизнес-логикой (кроме авторизации).

**Задание:**

- Создать REST API для доменов: Услуга (/api/stars/), Заявка на расчёт (/api/starcart/), Пользователь (/api/users/)

- Для всех GET-методов списков реализовать фильтрацию на бэкенде (для расчетов — по названию, для заказов — по статусу и диапазону submitted_at).

- Реализовать 21 метод согласно спецификации (см. ТЗ). 
- Пользователь во всех методах фиксирован. Системные поля (status, user, dates) изменяются только бизнес-логикой.

- Создать диаграмму классов (StarUML) с доменами, методами, моделями.

- Протестировать все методы в Postman/Insomnia (коллекция из 21 запроса).
